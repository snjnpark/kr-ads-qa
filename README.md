# kr-ads-qa

**광고 설정 검색과 운영 정책 점검을 한국어로.**

Meta · 네이버 검색광고 · Google Ads · 카카오모먼트 · 카카오 키워드광고를 조회합니다.

- 예산·일정·운영 조건으로 광고 검색
- 운영 정책에 맞는지 QA 점검
- 스냅샷 비교, 변경 이력, CSV 내보내기

## 🚀 시작하기

Node.js **24.10 이상 24.x**와 Git이 필요합니다.

```sh
git clone https://github.com/snjnpark/kr-ads-qa.git
cd kr-ads-qa
npm ci
npm run build
npm start
```

[localhost:8080](http://127.0.0.1:8080) → **설정 → 광고 API 연결**에서 인증 정보를 입력하고 데이터를 새로고침하세요. 개발할 때는 `npm run dev`를 사용합니다.

**Vercel 배포:** 저장소를 Import하고 Next.js · Node.js 24.x · `npm run build`를 선택하세요. API 키는 환경변수에 넣지 않습니다. 원격 셀프 호스팅에는 HTTPS와 `LAYA_PUBLIC_ORIGIN`을 설정하세요. [환경 예시](.env.example) · [배포 설정](vercel.json)

## 🔎 사용 전 확인

- **모델:** 별도 AI API 키 없이 브라우저에서 실행합니다. 처음 사용할 때 약 **769MB**를 내려받아 무결성을 확인하고 보관합니다. 메모리·저장 공간이 충분한 기기에서 사용하세요. [모델 Release](https://github.com/snjnpark/kr-ads-qa/releases/tag/model-lora-colab-v1)
- **데이터:** 광고 데이터와 이력은 브라우저에 저장하고 인증 정보는 현재 탭에서만 유지합니다. 새로고침 후에는 다시 연결해야 합니다. 데이터는 기기·브라우저·주소별로 분리되니 **설정 → 조회·이력 → 백업 다운로드**로 보관하세요. 백업에는 광고 데이터가 포함되고 인증 정보는 제외됩니다.
- **서버 중계:** 네이버 검색광고·카카오 키워드광고 조회만 일시 중계합니다. 앱은 중계 데이터와 인증 정보를 서버에 저장하지 않습니다. 인프라 접속 기록은 별도이며 요청 본문·인증 헤더를 수집하는 로그 도구는 연결하지 마세요. 질문·광고 데이터·인증 정보는 모델 호스트에 보내지 않습니다.
- **조회 범위:** 광고를 생성·수정·삭제하지 않습니다. 매체 권한·API 승인·쿼터·CORS에 따라 조회가 제한됩니다. GFA·톡채널검색은 지원하지 않습니다. 불명확한 질문은 보류할 수 있으니 결과의 근거와 조회 범위를 확인하세요.

실계정 API 연결과 원격 Vercel 운영은 별도 검증이 필요합니다.
