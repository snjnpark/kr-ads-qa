# kr-ads-qa

광고 설정을 한국어로 검색하고 예산·일정·운영 정책을 점검하는 웹 앱입니다. Vercel과 셀프 호스팅을 지원하며, 데이터 저장과 모델 실행은 사용자 브라우저에서 처리합니다.

- Meta·네이버 검색광고·Google Ads·카카오모먼트·카카오 키워드광고 조회
- 한국어 조건 검색과 운영 정책 QA
- 스냅샷 비교·변경 이력·CSV 내보내기·백업

광고 API는 읽기 전용으로 사용합니다. 광고를 생성·수정·삭제하지 않습니다.

## 실행

Node.js **24.10 이상 24.x**와 Git이 필요합니다.

```sh
git clone https://github.com/snjnpark/kr-ads-qa.git
cd kr-ads-qa
npm ci
npm run build
npm start
```

[http://127.0.0.1:8080](http://127.0.0.1:8080)에서 **설정 → 광고 API 연결**을 열어 인증 정보를 입력하고 데이터를 새로고침하세요. 개발 실행은 `npm run dev`를 사용합니다.

Vercel은 이 저장소를 Import해 Next.js·Node.js 24.x·`npm run build`로 배포합니다. API 키는 환경변수에 등록하지 않습니다. 원격 셀프 호스팅은 HTTPS와 `LAYA_PUBLIC_ORIGIN`을 설정하세요. [환경 예시](.env.example) · [Vercel 설정](vercel.json)

## 모델

별도 AI API 키는 필요하지 않습니다. 첫 자연어 사용 시 약 **769MB**를 다운로드하고 크기·SHA-256을 검증해 브라우저에 보관합니다. 이후에는 검증한 캐시를 재사용합니다. 충분한 메모리·저장 공간이 필요하며, 기기별 실행 가능 여부는 다를 수 있습니다.

원천 모델·토크나이저는 Hugging Face에서 브라우저가 직접 받습니다. 추가 학습 파일 4개는 [이 저장소의 모델 Release](https://github.com/snjnpark/kr-ads-qa/releases/tag/model-lora-colab-v1)에서 빌드 시 준비해 앱이 정적으로 제공합니다. 질문·광고 데이터·인증 정보를 모델 호스트에 보내지 않습니다.

## 데이터와 사용 범위

광고 데이터·정책·이력은 IndexedDB에, 인증 정보는 현재 탭의 메모리에 보관합니다. 새로고침하거나 탭을 닫으면 인증 정보를 다시 입력해야 합니다. 데이터는 기기·브라우저·접속 주소마다 분리되므로 **설정 → 조회·이력 → 백업 다운로드**로 보관하세요. 백업에는 광고 데이터가 포함되며 인증 정보는 포함되지 않습니다.

네이버 검색광고·카카오 키워드광고는 읽기 전용 서버 중계를 거치고, 나머지 매체는 브라우저에서 직접 요청합니다. 앱은 중계 데이터·인증 정보를 서버에 저장하지 않지만, 인프라의 접속 기록까지 없음을 보장하지 않습니다. 운영 시 요청 본문·인증 헤더를 수집하는 로그·분석 도구를 연결하지 마세요.

조회 범위는 매체 권한·API 승인·쿼터·CORS에 따라 달라집니다. GFA·톡채널검색은 지원하지 않습니다. 불명확하거나 지원하지 않는 질문은 보류할 수 있으므로 결과의 근거·조회 범위·확인 불가 항목을 확인하세요. 실계정 API와 원격 Vercel 운영은 별도 검증이 필요합니다.

공개 저장소에는 운영 소스와 배포 설정을 제공합니다. 개발 문서·테스트·합성 데이터·학습 도구는 로컬 관리 자료로 공개 clone에 포함되지 않습니다.
